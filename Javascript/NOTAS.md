## General:
- Javascript es sensible a mayusculas y minusculas.
- Respetar la sintaxis de tipo camel cas. getElementById
- Punto y coma al final de cada sentencia.
- Comentarios de tipo linea:
```javascript
// Soy un comentario xd
```
- Comentarios en tipo bloque:
```javascript
/*
Soy un comentario
    en bloque
        xd
*/
```
- El codigo comentado no se ejecuta
