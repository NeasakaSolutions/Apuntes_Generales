## Estructura del proyecto

El proyecto está organizado en carpetas, donde cada una corresponde a un módulo del video y contiene los apuntes realizados durante su desarrollo.

La estructura general cuenta con un archivo `index.html` como página principal y un archivo de estilos compartido para mantener una presentación uniforme en los diferentes módulos.

Los apuntes de **JavaScript** están organizados por módulos, por lo que cada tema cuenta con su propio archivo `.js`. Para probar un módulo específico, es necesario modificar la ruta del archivo JavaScript referenciado en el `index.html`, sustituyéndola por la correspondiente al módulo que se desea ejecutar.

De esta manera, se puede revisar y probar cada sección de los apuntes de forma independiente.
